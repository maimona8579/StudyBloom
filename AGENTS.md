# StudyBloom: instructions for AI coding agents

StudyBloom is a beginner-level student productivity website (plain HTML, CSS, JavaScript; data in browser localStorage; no backend, no login).

**Before doing anything, read these files in `docs/` in this order:**
1. `docs/Rules.md` (mandatory rules for you)
2. `docs/PRD.md` (requirements, decisions D1-D12, proposals P-01..P-23)
3. `docs/phases.md` (the roadmap; work one phase at a time)
4. `docs/TRD.md`, `docs/Architecture.md`, `docs/database.md`, `docs/appFlow.md`, `docs/design.md`

Key reminders (full list in `docs/Rules.md`):
- Work on ONE phase at a time, in order. Finish the Phase Gate (`docs/phases.md` section 2) before moving on.
- No frameworks, no CDNs, no external requests, no backend. Never use `innerHTML` with user or stored data.
- Never claim something was run, tested, committed or pushed unless it really was. Report results as Passed / Failed / Not tested / Blocked.
- The owner is a beginner: keep explanations short and simple.
- Do not commit or push to Git without the owner's confirmation.
- Project files (index.html, css/, js/, tests/) go in the project root, next to the `docs/` folder.
